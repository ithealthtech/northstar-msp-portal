Local development

Node.js 24 or later is required — the encrypted online backup uses the node:sqlite backup API from that runtime baseline.

npm install
Copy-Item .env.example .env.local
npm run build
npm run db:init
npm run start:development

Open http://127.0.0.1:4173. The local database defaults to data/northstar.db; migrations live in server/migrations and run automatically at startup.

!

Demo identities and synthetic portfolio data are off by default. To run the local-only demo, set DEMO_MODE=true and SEED_DEMO_DATA=true in .env.local. Never use those flags in production — production startup rejects them.

Microsoft Entra

Copy .env.example to .env.local and configure:

ENTRA_CLIENT_ID
ENTRA_TENANT_ID
ENTRA_API_AUDIENCE
ENTRA_API_SCOPE
ENTRA_ALLOWED_CLIENT_ID
ENTRA_REDIRECT_URI

Register these application roles:

RoleGrants a ceiling of
ClientPortal.UserEnd-user self-service
ClientPortal.AdminClient administration
ClientPortal.OwnerClient ownership
MSPPortal.AdminInternal MSP administration
MSPPortal.OwnerInternal MSP ownership

The access token must contain the Portal.Access delegated scope and exactly one recognized application role. The role is a ceiling — see the security model.

Provision an identity

Users are not created just-in-time. Provision the Entra tenant/object pair before first sign-in, or the user will authenticate successfully and reach nothing.

$env:PORTAL_USER_OID = "entra-object-id"
$env:PORTAL_USER_EMAIL = "person@example.com"
$env:PORTAL_USER_NAME = "Person Name"
$env:PORTAL_USER_ROLE = "client_admin"
$env:PORTAL_COMPANY_ID = "acme"
npm run user:provision

Supported database roles: client_user, client_admin, client_owner, msp_operator, msp_admin, msp_owner.

MSP identities may set PORTAL_PLATFORM_SCOPE=all. Otherwise their clients must be explicitly assigned in msp_company_scopes — an MSP admin does not implicitly see every client.

ConnectWise synchronization

Northstar uses ConnectWise Platform OAuth 2.0 client credentials with least-privilege platform.companies.read and platform.tickets.read scopes.

Configure CONNECTWISE_CLIENT_ID and CONNECTWISE_CLIENT_SECRET together, and select the regional CONNECTWISE_BASE_URL listed in .env.example. Production rejects non-ConnectWise origins.

i

The client secret and bearer token are never returned to the browser. Imported companies begin in onboarding state and are not automatically published to clients. Tickets are mapped through durable provider identifiers and idempotently upserted into company-scoped records.

Inspect or start a run through GET and POST /api/internal/integrations/connectwise/sync.

Going to production

!

The embedded SQLite store is a single-node pilot path. Before multi-instance rollout, migrate the same repository contracts to PostgreSQL, add tenant-qualified foreign keys and forced row-level security, run under a non-owner database role, and test RLS with the real deployment role.

Production operations include authenticated encrypted SQLite backups, integrity verification, offline-safe restore controls, configurable retention enforcement, database process leases, and health timestamps.

Read DEPLOYMENT.md, the release checklist, and the operations runbook before handling customer data.
